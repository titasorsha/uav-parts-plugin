# uav-parts plugin

Skill `drone-parts` plus the `uav-parts` tools on the invite-only server `https://parts.ironhoard.com/mcp`. You'll be asked for your personal access key (from your invite link) when the plugin is enabled. See the marketplace README for setup and what is sent where.

The skill in `skills/drone-parts/` is generated from `drone-parts-v2/` in the main (private) repository by `deploy/publish_plugin.sh`; edit it there, not here.
